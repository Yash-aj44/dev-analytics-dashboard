# Dev Analytics Dashboard 🚀

A modern frontend analytics dashboard built using HTML, CSS, and JavaScript.

## 🔥 Features
- Dark / Light theme toggle with localStorage
- Animated stat counters
- Interactive charts using Chart.js
- Project search filter
- Fully responsive layout
- Clean UI with modern design

## 🛠 Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Variables)
- JavaScript (DOM Manipulation, Animations)
- Chart.js (CDN)

## 📊 What I Learned
- Handling layout issues using Flexbox
- Debugging JavaScript errors using browser console
- Managing theme persistence with localStorage
- Creating dynamic UI updates with JavaScript
- Structuring frontend projects properly
